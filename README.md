# Эдем-Лоза — лендинг «Лоза как сервис»

Одностраничный сайт вымышленного виноградника: фиксированная процедурная 3D-сцена (React Three Fiber) на фоне всей страницы реагирует на скролл, курсор и время года.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # проверка типов + продакшен-сборка в dist/
npm run preview   # просмотр собранной версии
```

Внешних файлов нет: всё 3D, графика и иконки генерируются кодом, шрифты подключены локально через @fontsource.

## Где что менять

| Что | Где |
| --- | --- |
| Все тексты, отзывы, FAQ, данные дашборда, маркеры карты | `src/content/ru.ts` |
| Тарифы и цены (месяц/год) | `src/content/ru.ts` → `pricing.plans` |
| Палитра интерфейса (CSS-токены, шрифты) | `src/styles/index.css` → `@theme` |
| Цвета 3D: шкала созревания ягод, небо по временам года | `src/lib/constants.ts` |
| Хореография 3D по секциям (камера, гроздь, бокал, лучи, лозы) | `src/three/keyframes.ts` |

Типографика (неразрывные пробелы после предлогов, перед тире, в числах) применяется к `ru.ts` автоматически — `src/lib/typography.ts`.

## Как устроено

- `src/lib/scroll.ts` — Lenis, синхронизированный с GSAP ScrollTrigger. Каждая секция с атрибутом `data-scene` задаёт «секционное время» `t` (0 — hero, 1 — манифест…), по которому сцена интерполирует ключевые кадры.
- `src/three/` — сцена: гроздь (InstancedMesh, ягоды по золотому углу, MeshPhysicalMaterial с transmission), лозы и листья с шейдером ветра, частицы, бокал с жидкостью-шейдером, небо-градиент, лучи, постобработка.
- Качество подстраивается само (`PerformanceMonitor`): high → medium → low (постобработка, transmission, DPR). На телефонах меньше ягод и частиц, пин-секции заменены обычной вёрсткой.
- `prefers-reduced-motion`: без Lenis, параллакса и длинных анимаций, сцена статична. Без WebGL — CSS/SVG-фолбэк.
- Диагностика шейдеров: добавьте `?debug` к адресу.
